Решение тестового задания на стажировку Data Science в Авито.

Автор: Максим Матяшов

Цель задачи: для каждого поискового запроса отобрать до 50 релевантных объявлений из корпуса. Основная метрика - Recall@50.

Итоговый результат Recall@50: 0.616331

Архитектура решения
  Решение использует ансамбль трех алгоритмов поиска:
  TF-IDF с косинусным сходством
  BM25 для лексического поиска
  Семантический поиск через Sentence Transformers

Для быстрого поиска по векторам применяется FAISS. Скоры разных моделей нормализуются и суммируются с оптимальными весами. Также реализован бустинг объявлений, находящихся в той же локации, что и запрос.

Структура проекта:
  data/raw/ - исходные данные в формате parquet
  data/processed/ - обработанные данные, векторизаторы и эмбеддинги
  notebooks/ - jupyter ноутбуки с этапами решения
  answer.csv - финальный файл с предсказаниями

Основные библиотеки:
  pandas, numpy, scikit-learn
  pyarrow
  rank_bm25, nltk
  sentence-transformers, torch
  faiss-cpu

Запуск
Для корректной работы проекта, создайте папку data/ в корне, в ней также создайте raw/ и processed/. В raw/ добавьте все файлы задания. Поочерёдно воспроизведите все ноутбуки. "answer.csv" будет создан в корне проекта.

Для поиска кандидатов использовались тексты запросов и объявлений, категории и локации. Текст является основным сигналом, а категории и локации применяются для фильтрации и географического бустинга. Решение представляет собой ансамбль из TF-IDF, BM25 и модели Sentence Transformers. Векторный поиск ускоряется через FAISS, итоговый скор вычисляется как взвешенная сумма нормализованных метрик с учетом региона пользователя. 

Качество оценивалось на отложенной выборке из 20% уникальных запросов по метрике Recall@50, на которой также подбирались веса алгоритмов. В ходе решения встретил ошибки смешанных типов данных, исправил их явным приведением к стандартным числовым форматам, проблемы индексации решены переходом к фильтрации по ID. Пропуски заполнил медианой с добавлением бинарных флагов.
